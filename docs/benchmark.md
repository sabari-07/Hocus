# Benchmark: resolving "that" on simulated users

Generated by `npm run bench` (`scripts/benchmark.ts`). Seed **2026**, **600** trials per condition, 6 targets.

**These are simulated users, not people.** The simulator (`packages/testkit/src/simulate.ts`) moves a pointer from a decoy object to a target, dwells, speaks "make that bigger" with a random recognizer lag, and sometimes leaves early. After speaking it keeps pointing (40%), drifts to empty space (30%) or moves to another object (30%). It is useful for comparing strategies, not for claiming real-world accuracy. Real recorded sessions go in `tests/replays/`.

- **Correct**: bound to the intended object. **Wrong**: bound to another object (the costly error). **Ask**: Hocus asked which one. **None**: no target.
- Baselines take one pointer sample at one moment and never ask. The oracle knows the true word time, which no real system does.
